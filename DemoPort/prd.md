# 개발자 프로필 웹사이트 PRD (Product Requirements Document)

## 1. 개요

|---|---|
| 프로젝트명 | DemoPort - 개발자 프로필 웹사이트 |
| 목적 | 개발자 개인 프로필/포트폴리오를 소개하는 반응형 웹사이트 제작 |
| 대상 사용자 | 채용 담당자, 협업 파트너, 클라이언트 등 프로필을 조회하는 방문자 |
| 문서 상태 | Draft v1.0 |

|---|---|

## 3. 목표

- 방문자가 한눈에 개발자의 정체성과 전문 분야를 파악할 수 있도록 한다.
- 연락 수단(이메일)을 명확하게 노출하여 컨택 포인트를 확보한다.
- 추후 프로젝트/작업물을 손쉽게 추가할 수 있는 구조로 설계한다.

## 4. 범위 (Scope)

### 포함 (In Scope)
- 단일 페이지(One Page) 형태의 프로필 소개 웹사이트
- 이름, 이메일, 주 개발 분야를 포함한 자기소개 섹션
- 반응형 레이아웃 (데스크톱/모바일 대응)

### 제외 (Out of Scope)
- 백엔드/데이터베이스 연동
- 로그인, 관리자 페이지 등 동적 기능
- 다국어 지원 (1차 버전은 한국어만)

## 5. 정보 구조 (Information Architecture)

1. **헤더(Header)**
   - 이름, 짧은 타이틀(예: "바이브코딩 개발자")
2. **소개(About)**
   - 개발자 소개 문구
   - 주 개발 분야 태그: 바이브코딩, Python, HTML5
3. **연락처(Contact)**
   - 이메일: xiaromance@gmail.com
   - (선택) 이메일 클릭 시 mailto 링크 연결
4. **푸터(Footer)**
   - 저작권/이름 표기

## 6. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F-01 | 이름, 이메일, 주 개발 분야가 페이지 최초 진입 시 즉시 노출되어야 한다 | High |
| F-02 | 이메일 클릭 시 메일 작성 화면(mailto:)으로 연결되어야 한다 | Medium |
| F-03 | 주 개발 분야(바이브코딩/Python/HTML5)는 뱃지(태그) 형태로 시각화한다 | Medium |
| F-04 | 모바일 화면(360px 이상)에서도 레이아웃이 깨지지 않아야 한다 | High |

## 7. 비기능 요구사항

- **기술 스택**: HTML5, CSS3, (필요 시) 순수 JavaScript
- **성능**: 정적 페이지로 별도 서버 없이 로컬/정적 호스팅에서 즉시 구동 가능해야 한다
- **접근성**: 시맨틱 태그 사용, 색상 대비 확보
- **호환성**: 최신 Chrome/Edge 기준 정상 동작

## 8. 디자인 가이드 (초안)

- 톤앤매너: 개발자다운 심플하고 모던한 느낌 (다크 테마 또는 미니멀 라이트 테마)
- 강조 색상: 포인트 컬러 1개 지정 (예: 청록/블루 계열)
- 폰트: 가독성 높은 시스템 폰트 우선 사용

## 9. 향후 확장 (Future Scope)

- 프로젝트/포트폴리오 목록 섹션 추가
- GitHub, LinkedIn 등 외부 링크 추가
- 블로그/기술 글 연동

## 10. 산출물

- `index.html` (또는 이에 준하는 메인 페이지 파일)
- 관련 CSS/JS 리소스 (필요 시 별도 파일 분리)
